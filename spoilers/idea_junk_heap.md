# Idea Junk Heap

Superseded ideas — kept for reference so we don't accidentally re-invent or contradict something that was deliberately dropped. Not current design; see `game_design.md` and other `spoilers/` docs for what's actually active.

---

## Crafting table at start of game, in circle

**Old idea**: A crafting table spawns for free in the player's home stone circle at world init (documented in `game_design.md` under "Starting Circle" / "Tool System" — "Free crafting access from the start").

**Replaced by**: The player has no 3x3 crafting access at all for most of the game — only the 2x2 personal-inventory grid, plus whatever villagers sell. A crafting table becomes obtainable only near end-game, likely via a villager trade (possibly the Wandering Trader), not by crafting one directly. This pushes the low-durability/limited-tools philosophy further back and makes reaching a crafting table itself feel earned rather than given.

**Status**: `game_design.md` has been updated to reflect the replacement.

---

## Soul lantern in starting chest

**Old idea**: The starting chest contained a soul lantern — described as "a mystery, at this point - used in middle game." No mechanic was ever attached to it.

**Replaced by**: Dropped from the starting chest redesign (see `game_design.md` "Starting chest"), which now contains a brown mushroom, a map to the nearest village, a book of lore, and a writable book of potions. If a middle-game mystery item is still wanted, it isn't this one — would need a fresh idea with an actual attached mechanic.

**Status**: `game_design.md` has been updated to reflect the removal.

## Unnamed tag in starting chest

**Old idea**: The starting chest contained a tag with no name yet — described as "a mystery, at this point - used in endgame." No mechanic was ever attached to it.

**Replaced by**: Dropped from the starting chest redesign for the same reason as the soul lantern. Note the endgame already has its own name tag requirement (inscribed "BELAATRIX," see `end_game.md`) — that one is unrelated to this dropped item and is obtained separately via anvil, not from the starting chest.

**Status**: `game_design.md` has been updated to reflect the removal.
